
# Redistribution Labs

This folder contains hands-on route redistribution labs, built and tested in PNetLab. Each lab is documented with a topology diagram, configuration, verification steps, and a WHAT-I-LEARNED file covering mistakes made and concepts reinforced along the way.

About These Labs

These labs are part of hands-on practice following networking training (CompTIA Network+, CCNA). Each lab is built from scratch in PNetLab and documented here as a record of real, verifiable work - not certifications, just genuine practice and learning.

More labs will be added here over time, covering different redistribution scenarios (route-maps, distribute-lists, seed metrics, route filtering, loop prevention, etc.).
